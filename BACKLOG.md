# The backlog

The backlog lives in **GitHub Issues** with the `backlog` label:
https://github.com/The-LoreMaster/lorefell-forge/issues?q=is%3Aopen+label%3Abacklog

## How it is kept

- Every new idea, ruling or bug that is not fixed the same day becomes an issue, labelled `backlog` plus its area.
- Every pull request says which issue it moves: `Closes #n` when it finishes one, `Part of #n` when it advances one, or `Backlog: none` when it touches nothing on the list. The pull request template asks.
- When work is finished, the issue closes with the pull request; anything left over becomes a new issue rather than a forgotten line.
- An item Nate drops is closed by a pull request too (its body says Closes #n), with the reason in BACKLOG.md.

## Labels

| Label | Means |
| --- | --- |
| `backlog` | Planned work |
| `threadspire` | The table |
| `anexanum` | The Anexanum and YouTube |
| `rules` | A FellGuide rule not yet at the table |
| `fellguide` | The FellGuide vault |
| `decision` | Needs a decision from Nate before it is built |
| `waiting:art` | Waiting on art or another person |
